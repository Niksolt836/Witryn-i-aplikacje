1. W jaki sposób można określić właściwość obiektu?

Sposób 1 – notacja kropkowa:
obiekt.imie = "Jan";

Sposób 2 – notacja tablicowa:
obiekt["imie"] = "Jan";

2. Jak odwołujemy się do pól i metod?

Pole:
obiekt.wiek;

Metoda:
obiekt.przywitaj();

3. Cechy charakterystyczne konstruktora

  • Jest wywoływany podczas tworzenia obiektu
  • Ustawia wartości początkowe
  • Ma nazwę klasy (lub funkcji konstruktora)
  • Używa słowa this

4. Obiekt z trzema polami i jedną metodą

let osoba = { imie: "Anna", wiek: 20, miasto: "Warszawa", przedstawSie: function() { alert("Jestem Anna"); } };

5. Znaczenie słowa this

this oznacza aktualny obiekt.

Oddzielamy pola i metody kropką:
this.imie
this.przedstawSie()

6. Konstruktor w JavaScript

function Osoba(imie, wiek) { this.imie = imie; this.wiek = wiek; }

Opis: Konstruktor tworzy nowe obiekty i przypisuje im dane.

7. Słowo kluczowe new

let osoba1 = new Osoba("Jan", 30);

new tworzy nowy obiekt na podstawie konstruktora.

8. Słowo kluczowe prototype

Osoba.prototype.przywitaj = function() { alert("Cześć!"); };

Prototype pozwala dodawać metody do wszystkich obiektów danej klasy bez kopiowania ich w każdym obiekcie.
Dzięki temu oszczędzamy pamięć i kod jest wydajniejszy.
