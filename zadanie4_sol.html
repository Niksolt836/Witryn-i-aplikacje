JavaScript - Pytania i Odpowiedzi

1) Kiedy powstał JavaScript (podaj datę).
JavaScript został stworzony w grudniu 1995 roku przez Brendana Eicha w firmie Netscape.

2) Dlaczego jest to język skryptowy.
Ponieważ wykonywany jest bezpośrednio przez interpreter, bez potrzeby wcześniejszej kompilacji do kodu maszynowego.

3) Gdzie jest wykonywany JS (klient lub serwer).
Początkowo JavaScript działał tylko po stronie klienta, ale obecnie może działać również po stronie serwera (np. Node.js).

4) Dlaczego jest JS to bezpieczne narzędzie.
Ponieważ działa w tzw. sandboxie przeglądarki, co ogranicza jego dostęp do systemu operacyjnego i plików użytkownika.

5) Czy jest to język obiektowy, jeśli tak to dlaczego.
Tak, ponieważ w JavaScript wszystko jest obiektem (np. tablice, funkcje, daty) i można korzystać z mechanizmów programowania obiektowego.

6) Wymień zalety JS:
Zaleta 1: Działa na wszystkich popularnych przeglądarkach.
Zaleta 2: Umożliwia interaktywność stron WWW.
Zaleta 3: Posiada ogromną liczbę bibliotek i frameworków wspierających tworzenie aplikacji.

7) Framework to:
Gotowy szkielet oprogramowania ułatwiający tworzenie aplikacji, dostarczający zestaw narzędzi, bibliotek i struktur.

8) Do aplikacji mobilnych można użyć Framework:
React Native, Ionic, Flutter (z wykorzystaniem JavaScript/TypeScript).

9) Aplikacje responsywne to:
Strony lub aplikacje, które automatycznie dopasowują wygląd i układ do różnych urządzeń (komputery, tablety, smartfony).

10) Przepisz linie kodu pod nimi wytłumaczenie jak działa ten fragment kodu
‹input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen(' ')"›
Ten fragment tworzy przycisk o nazwie „Nowa Strona”. Po jego kliknięciu wywoływana jest funkcja WinOpen(), która może otworzyć nową stronę lub okno.

11) Przepisz linie kodu pod nimi wytłumaczenie jak działa ten fragment kodu
window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");

Ten kod otwiera nowe okno przeglądarki z plikiem obraz.html o określonych parametrach.

toolbar=no → ukrywa pasek narzędzi przeglądarki.
directories=no → ukrywa przyciski katalogów (starsze przeglądarki).
menubar=no → ukrywa menu przeglądarki.
height=280 → wysokość okna to 280 pikseli.
width=160 → szerokość okna to 160 pikseli.
top=200 → okno pojawi się 200 pikseli od górnej krawędzi ekranu.
left=200 → okno pojawi się 200 pikseli od lewej krawędzi ekranu.

12) Opisz następującą instrukcję window.close()
Instrukcja window.close() zamyka aktualnie otwarte okno przeglądarki
