Pętla for

Nazwa pętli: for

Konstrukcja:
for(inicjalizacja; warunek; zmiana)
{
  instrukcje
}

Opis:
Pętla for jest używana wtedy, gdy znamy liczbę powtórzeń. Najpierw wykonywana jest inicjalizacja zmiennej, potem sprawdzany jest warunek. Jeśli warunek jest spełniony wykonywane są instrukcje pętli, a następnie zmieniana jest wartość zmiennej.

Schemat blokowy:
Start → inicjalizacja → sprawdzenie warunku → instrukcje → zmiana → powrót do warunku → Stop

Pętla while (z kontrolowanym wejściem)

Nazwa pętli: while

Konstrukcja:
while(warunek)
{
  instrukcje
}

Opis:
Pętla while najpierw sprawdza warunek. Jeżeli warunek jest prawdziwy wykonywane są instrukcje. Jeżeli warunek jest fałszywy pętla nie wykona się ani razu.

Schemat blokowy:
Start → sprawdzenie warunku → TAK → instrukcje → powrót do warunku → NIE → Stop

Pętla do...while (z kontrolowanym wyjściem)

Nazwa pętli: do...while

Konstrukcja:
do
{
  instrukcje
}
while(warunek);

Opis:
Pętla do...while najpierw wykonuje instrukcje, a dopiero potem sprawdza warunek. Dlatego instrukcje wykonają się co najmniej jeden raz.

Schemat blokowy:
Start → instrukcje → sprawdzenie warunku → TAK → powrót do instrukcji → NIE → Stop
